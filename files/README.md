# Static Files & Downloadable Assets (`files/`)

Place downloadable documents (such as your PDF Curriculum Vitae, manuscript preprints, and presentation slides) in this directory.

## Recommended File Naming
* **Curriculum Vitae:** Place your PDF CV here as `files/Sandeep_Singh_CV.pdf`. It is already linked from `_pages/cv.md` at `{{ base_path }}/files/Sandeep_Singh_CV.pdf`.
* **Publication Preprints / Supplements:** Place PDFs here (e.g., `files/2026-glioma-triage.pdf`) and reference them in the `paperurl` frontmatter field of items in `_publications/`.
* **Talk Slides:** Place slide decks here (e.g., `files/2026-glioma-audit-slides.pdf`) and reference them in `_talks/`.
