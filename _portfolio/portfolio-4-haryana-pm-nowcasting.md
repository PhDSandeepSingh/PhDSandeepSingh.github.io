## System Overview
An hourly $\text{PM}_{2.5}$ and $\text{PM}_{10}$ nowcasting framework across **24 cities in Haryana** trained on continuous CPCB and HSPCB monitoring data.

### Key Highlights
* **Six-Architecture ML/DL Comparison:** Benchmarks classical machine learning models alongside four recurrent neural network architectures (**LSTM, GRU, Bi-LSTM, and Bi-GRU**), eliminating cross-architecture hyperparameter sharing bugs to guarantee fair model-to-model comparison.
* **Statistical Validation:** Evaluates all models against a naive persistence baseline with formal statistical significance testing.
* **Springer Nature Manuscript:** Audited via a structured three-pass peer-review workflow and typeset in Springer Nature (`sn-jnl`) LaTeX format targeting a Q1/Q2 journal.
